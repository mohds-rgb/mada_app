# اختبارات قواعد الأمان (Firestore Rules) — بند 6-10، 12-ط

اختبارات القواعد الآلية الكاملة تحتاج Firebase Emulator Suite (Node.js +
`firebase-tools` + حزمة `@firebase/rules-unit-testing`) — بيئة منفصلة عن
Flutter/Dart. هذا خارج نطاق ما يمكن تجهيزه ضمن مشروع Flutter وحده، وسيُبنى
تدريجياً بالمراحل القادمة بالتوازي مع كل مجموعة بيانات جديدة (بند 12-ط:
"مراجعة شاملة نهائية" قبل الإطلاق العام تشمل تشغيل المجموعة كاملة).

## ما هو مُغطّى الآن يدوياً (المرحلة 0)
راجع `firestore.rules` بالجذر — كل قاعدة موثَّقة بتعليق يشرح المنطق ومرجع
البند المطابق بمواصفة المشروع.

## خطوة بشرية لاحقة (عند الرغبة بتفعيل اختبارات القواعد الآلية)
1. `npm install -g firebase-tools`
2. `firebase init emulators` (اختر Firestore Emulator) من جذر المشروع.
3. `npm install --save-dev @firebase/rules-unit-testing` ضمن مجلد اختبارات Node منفصل.
4. تُكتَب سيناريوهات مثل: "عميل عادي يحاول تعديل role إلى owner → يجب الرفض"،
   "سائق يحاول تعديل walletBalance مباشرة → يجب الرفض"، إلخ.

سيُطلَب منك صراحة تنفيذ الخطوة 1-2 (تثبيت أدوات) عند الوصول لهذه النقطة —
لا تفترض تنفيذها تلقائياً (بند 6-9).
